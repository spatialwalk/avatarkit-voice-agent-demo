# Avatarkit Voice Agent Demo

A repository of examples showing how to build lip-synced voice agents using AvatarKit by [SpatialReal](https://www.spatialreal.ai/).

- Livekit Agents: `livekit-agents`
- SpatialReal Agent Quickstart (React + AvatarKit UI): `spatialreal-agent-quickstart`
- SpatialReal Speech-to-Avatar Quickstart: `spatialreal-speech-to-avatar-quickstart`
